需要上传什么样的压缩包？

只支持由 Unity 导出的 WebGL 构建产物压缩而成的 ZIP，压缩包内必须包含 WebGL 运行文件（.wasm / .unityweb）和入口页面 index.html，否则导入后状态会显示为“无效”。

@if (noteExpanded()) {
Unity 打包成 WebGL 压缩包的具体步骤
  1. 在 Unity 中打开或创建仿真项目，选择菜单 文件 → 生成设置，在左侧平台列表选择 WebGL。若列表里没有 WebGL，需先在 Unity Hub 中为当前编辑器版本安装 WebGL 生成支持模块，安装完成后重启 Unity。
  2. 点击 播放器设置 可调整分辨率、压缩格式等参数，一般保持默认即可。建议将压缩格式设为 Gzip 或 Brotli（会生成 .unityweb 文件，兼容性更好）。
  3. 点击 生成（或“生成并运行”），选择一个空的输出文件夹，等待构建完成。首次构建耗时较长，属正常现象。
  4. 构建完成后，输出文件夹内会生成 index.html、Build/ 目录（内含 .wasm、.data、.framework.js、.loader.js 等）和 TemplateData/ 目录，这一整套即为 WebGL 构建产物。
  5. 进入该输出文件夹，全选全部内容后右键压缩为 ZIP。Windows：发送到 → 压缩(zipped)文件夹；macOS：压缩“N 个项目”。建议不要把外层文件夹一起压缩，保持 index.html 位于压缩包根目录。
  6. 回到本页面点击“新增镜像”，填写名称、上传封面（可选），选择刚生成的 ZIP 上传并导入。系统会自动定位 index.html 并检测 WebGL 文件，识别成功的镜像状态为“已就绪”。
压缩包内必须包含一个 index.html 及 WebGL 运行文件（.wasm / .unityweb）。缺少这些文件时，镜像导入后状态会显示为“无效”，无法打开运行，请按上述步骤重新打包后再上传。

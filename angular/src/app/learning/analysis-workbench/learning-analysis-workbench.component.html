为什么是这个顺序
  • 知识点是所有分析的地基：OCR 靠知识点匹配题目，掌握率、章节达成度也都按知识点统计；灰区未确认会让统计口径不稳。
  • 课程联动是结构配置：教学诊断里「加强前置课程」的建议要靠前后关系与复习包推送才能真正落地。
  • 试卷采集产生原始数据：未校对的低置信度题目不能进入分析，否则班级薄弱点会算错。
  • 分析报告是出口：只有已确认的批次才能生成薄弱点、诊断与学生报告，再推送 / 导出 / 留档。

# 2026-11-22 工作日志

## 学生端工作台首页与标准导航架构

- 用户要求：学生端加类似工作台的首页，显示当前可用模块并可跳转；参考常见安卓 App 的导航 Tab 和页面组织，让用户清楚了解并使用功能，后续新模块能快速跳转。
- 新增 `android-client/app/src/main/java/com/knowledgehub/mobile/ui/common/AppModules.kt`：
  - `AppModule` 统一描述模块 ID、名称、图标、描述、颜色、是否进底部导航、是否可用。
  - `AppModules.student` 注册 5 个一级模块：工作台、我的学习、课程中心、学习统计、设置。
  - `AppModules.studentUpcoming` 预留作业、资源库、消息通知，设 `enabled=false`，工作台显示“即将开放”。
  - `AppBottomNavigation` 作为通用 Material3 底部导航，由注册表驱动。
- 新增 `android-client/app/src/main/java/com/knowledgehub/mobile/ui/student/WorkbenchTab.kt`：
  - 欢迎卡片显示登录用户、租户和学习概览（学习中/已完成/习题记录/累计学习时长）。
  - 常用模块 2 列卡片网格从 `AppModules` 生成，点击进入对应 Tab。
  - 继续学习展示前 2 门课程，可直接进入详情或章节学习；空态引导去课程中心。
  - 更多功能区域展示即将开放模块占位。
- 重构 `StudentScreen.kt`：
  - 一级页面状态由 `Int` 下标改为模块 ID，避免新增模块时改多处魔法数字。
  - `selectModule` 统一处理禁用模块提示、Tab 切换与数据加载。
  - `reloadModule` 按模块 ID 加载对应数据。
  - 课程详情/章节学习返回改为统一函数，并接入 `BackHandler`，实现「章节学习 → 课程详情 → 当前 Tab → 工作台」逐级返回。
- 验证：
  - `compileDebugKotlin`、`assembleDebug` 成功。
  - qidi 租户 `zmq` 登录成功，工作台显示「学习中 4 / 已完成 1 / 习题记录 25 / 累计 184 分」和 7 门继续学习课程。
  - 点击工作台「课程中心」卡片进入课程中心，顶部标题与底部导航选中态正确；5 个底部 Tab 均可切换。
  - 即将开放模块为灰色占位，点击提示“即将开放”，不会误跳页面。
- 文档：更新 `android-client/ANDROID_MIGRATION_PLAN.md` 的 MVP 能力、目录结构、导航约定和实测记录。

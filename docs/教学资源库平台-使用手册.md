## 0. 手册说明

### 0.1 平台支持的三种教学资源库形态

| 形态 | 平台中的叫法 | 前台可见 | 谁能学习 | 参建单位 | 跨校共享 |
|---|---|---|---|---|---|
| 校级私有库 | 非共享资源库 | 所有人可见可浏览（封面 / 简介） | **仅课程老师导入班级的学员** | 不允许 | 不允许 |
| 校级共享库 | 共享资源库（单校） | 所有人可见 | 本校学生 + **实名认证后的其他学员** | 不允许 | 不允许 |
| 校际共建库 | 共建共享资源库 | 所有人可见 | 主建校 + 参建单位 + 实名认证后的其他学员 | 允许 | 仅限参建单位 |

形态在「资源库形态」下拉框中选择，创建后仍可在编辑时调整。

### 0.2 角色与权限

| 角色 | 能做什么 |
|---|---|
| 平台管理员 | 证书模板配置、跨校证书审核；参建单位挂载、院校域名绑定、账号有效期 |
| 主建单位老师（库创建者） | 本库全部管理权；授权外校老师参与共建；**审核本机构库的课程证书** |
| 参建单位老师 | 上传 / 管理自己上传的内容与班级学生 |
| 导入学员 | 老师建班级导入的学生，学习本机构课程 |
| 其他学员 | 未经过班级导入、自行注册学习的外部用户，**需手机号 + 实名认证**方可学习 |

## 1. 账号认证

### 1.1 手机认证 + 实名认证

**入口**：学生端 → 个人中心（`/student/profile`）→ 账号安全。

![个人中心-手机认证与实名认证](screenshots/prod/01-student-profile-verification.png)

操作要点：

1. 点「手机认证」，弹窗中确认手机号（须与账号绑定手机号一致）；提交后状态由「未认证」变「已认证」。
2. 点「实名认证」，填写**真实姓名**与**身份证号**（18 位，系统校验格式与校验位）；提交后状态变「已实名」，并显示脱敏身份证号（`1101************17`）。

**为什么必须先实名**：实名认证是学习「对外开放」资源库课程的前置条件。

| 身份 | 未实名 | 已实名 |
|---|---|---|
| 本校学生 | 可学本校课程 | 可学本校课程 |
| 其他学员 / 外校学生 | 选课被拦截 | 可学**校级共享库**、**校际共建库**课程 |

被拦截时的提示：

```
「qidi 校级共享教学资源库」对外开放学习，请先在个人账户完成实名认证后再学习。
```

> 说明：当前生产环境尚未接入短信网关，「手机认证」的口径是「提交手机号与账号绑定手机号一致」；实名认证做身份证格式校验。接入短信与权威核验后，此处会升级为验证码 + 权威核验。

## 2. 创建与维护教学资源库

### 2.1 入口

管理端 → 资源库管理 → **教学资源库管理**（`/admin/libraries`）。

![教学资源库管理列表](screenshots/prod/02-admin-libraries-list.png)

列表各列含义：

| 列 | 说明 |
|---|---|
| 资源库 / 简介 | 库名与建设说明 |
| 主建专业 | 库的专业标签（用于展示与筛选，不限制库内内容） |
| 建设负责人 | 门户卡片展示的自然人姓名 |
| 共建关系 | 主建学校 + 参建学校（红色「合作 N 校」） |
| 内容 | 库内课程 / 资源数量 |
| 状态 | 形态标（校级私有库 / 校级共享库 / 校际共建库）+「对外开放自学」标 + 发布状态 |
| 操作 | 共建学校、分配教师、编辑、归档、删除 |

### 2.2 新建资源库

点「新建资源库」，填写名称、简介、封面、建设负责人、**资源库形态**。

![新建教学资源库](screenshots/prod/03-admin-library-create.png)

| 字段 | 说明 |
|---|---|
| 资源库形态 | 校级私有库 / 校级共享库 / 校际共建库，下方实时显示该形态的规则说明 |
| 对外开放自学 | 仅共享库 / 共建库可开；开启后其他学员实名即可学习并申请课程证书；**私有库强制关闭** |
| 在门户公开展示 | 关闭则门户与院校主页不展示 |
| 建设负责人 | 展示在门户资源库卡片 |

保存后资源库为**草稿**状态，需在列表点「发布」才会出现在门户。

### 2.3 参建单位（仅校际共建库）

在库行点「共建学校」→ 选择参建机构 → 点「加入」。

![共建学校设置](screenshots/prod/04-admin-library-members.png)

上图即生产环境实测：`qidi · 东燕 校际共建教学资源库` 的主建学校为「中医专业资源库（qidi）」，参建学校为「传媒类资源库（dongyan）」。

> PRD 规定参建单位由**平台管理员**挂载；当前版本由主建单位的院校管理员添加，平台管理员可代为操作。

### 2.4 分配教师

在库行点「分配教师」→ 选择本校教师 → 保存。教师随后可在「教学资源库工作台」建设该库。

### 2.5 课程入库与跨校共享约束

课程挂进资源库后，其**跨校共享范围**由库形态决定，服务端强制校验：

| 库形态 | 共享给其它学校 | 共享给「社会学校」（对外自学通道） |
|---|---|---|
| 校级私有库 | ❌ 拒绝 | ❌ 拒绝 |
| 校级共享库 | ❌ 拒绝 | ✅ 允许（学员需实名认证） |
| 校际共建库 | ✅ 仅限参建单位 | ✅ 允许（学员需实名认证） |

教师发布课程时若勾选「共享课」而课程属于受限的库，服务端会返回：

```
「qidi 校级共享教学资源库」是校级共享库，按需求库内课程仅限校内共享，不能共享给其他学校。
```

## 3. 学习与「其他学员」

### 3.1 学员选课与学习

学生端 → 课程中心 → 「公共课程」区域展示**共享库 + 共建库**的课程，卡片标注来源学校，实名认证后可直接选课。

![学生课程中心-公共课程](screenshots/prod/06-student-courses-public.png)

上图（dongyan 学生 `dy`）可见：qidi 共享库的《网络安全技术》《计算机网络技术基础》均为 100% 进度，dongyan 本校课程亦在列表中。

学习权限矩阵：

| 学习者 | 校级私有库 | 校级共享库 | 校际共建库 |
|---|---|---|---|
| 本校学生 | 仅老师导入 / 分配的学员 | ✅ | ✅ |
| 其他学员 / 外校学生 | ❌ | ✅ 实名后 | ✅ 实名后 |

### 3.2 「其他学员」目录（PRD 5.3）

管理端 → 资源库管理 → **其他学员目录**（`/admin/other-learners`）。

![其他学员目录](screenshots/prod/07-admin-other-learners.png)

规则：

- 「其他学员」是**系统级默认目录**，老师无需手动创建；
- 校外学员首次选课时，系统自动在**主建老师**账号下建档（姓名取实名、手机号取账号）；
- 目录内学员**不归属任何班级**，与老师自建班级天然隔离；
- 该库从未产生其他学员学习记录时，目录为空态、不占位；
- 支持按库筛选、按姓名 / 手机号搜索、**导出 Excel**。

上图中 `东燕学员` 由 dongyan 学生 `dy` 首次学习 qidi 共享库课程时自动生成，已实名、已绑定手机，证书 2 张。

## 4. 课程证书

> 课程证书 = 教学资源库课程结业后申请的电子证书；与「微专业证书」是两套体系（见 4.6）。

### 4.1 学员申请

**入口 1**：课程学习页右上角「申请课程证书」（习题进度 100% 且通过考核后出现）。

![课程学习页-申请课程证书](screenshots/prod/08-student-course-learn-cert.png)

**入口 2**：学生端 → **课程证书** → 「申请课程证书」页签。

**申请条件**（服务端逐条校验）：

1. 课程习题进度 100%（该课程全部可学习习题都已作答）；
2. 通过课程考核（课程配置了考试时须有通过的考试记录）；
3. 已完成账号实名认证；
4. 同一课程没有待审核 / 已发证的申请。

### 4.2 审核与发放

管理端 → 资源库管理 → **课程证书中心**（`/admin/certificates`）→ 「申请审核」页签。

![课程证书中心-申请审核](screenshots/prod/09-admin-certificates-review.png)

- **库所有者（院校管理员）**：只看到本机构主建库的申请，可审核发放；跨机构发证会被拒绝。
- **平台管理员**：可审核全部院校申请，并额外拥有「证书模板」页签（模板由平台统一定义，院校不可自定义）。

点「审核并发证」进入发证弹窗：左侧是按模板实时合成的证书预览，右侧可调整学员姓名、课程名称、学校名称、资源库名称、结业时间、证书编号。

![审核通过并发证](screenshots/prod/09b-admin-certificate-issue.png)

确认后系统会：合成证书图片并上传对象存储 → 写入证书记录（含证书编号与防伪码）→ 归档到主建老师「其他学员」目录下该学员的档案。

### 4.3 学员查看与下载

学生端 → **课程证书** → 「课程证书」页签，可查看证书图片并点「下载证书」下载 PNG 图片。

![学生端课程证书-下载](screenshots/prod/10-student-certificates-download.png)

> 证书图片存放在对象存储（跨域），下载时前端自动经站内图片代理取流，不受跨域限制；单文件为原始分辨率的 PNG。

### 4.4 防伪核验

公开核验页：`https://www.iketong.com/verify/certificate`，输入**证书编号**或**防伪码**即可核验真伪。

![证书防伪核验](screenshots/prod/11-certificate-verify.png)

### 4.5 证书模板（平台侧）

平台管理员在「课程证书中心 → 证书模板」维护：上传底图 → 在画布上摆放占位符（学员姓名 / 课程名称 / 学校名称 / 结业时间 / 证书编号 / 防伪码）→ 设为默认 / 启用。

生产环境默认模板：`教学资源库课程证书`（16:9 空白底图 + 校徽位 + 5 个占位符图层）。

### 4.6 课程证书 vs 微专业证书

| | 课程证书 | 微专业证书 |
|---|---|---|
| 学生端菜单 | 课程证书 | 微专业证书 |
| 业务对象 | 教学资源库中的一门课程 | 微专业（培养路径） |
| 申请方式 | 学员完成课程习题 + 考核后申请，机构管理员审核发放 | 教师在微专业后台直接发证 |
| 模板 | 平台统一配置，院校不可自定义 | 微专业下自行配置 |
| 核验 | 平台公开核验页 | 平台未提供第三方验真服务 |
| 下载 | 卡片「下载证书」 | 预览弹窗内下载（画布合成） |

## 6. 常见问题与边界（PRD 第 10 章）

| 场景 | 平台行为 |
|---|---|
| 未登录访问私有库学习页 | 引导登录；登录后仍非导入学员 → 提示「请联系课程老师加入班级」 |
| 其他学员未实名就点学习 | 拦截并提示先完成手机号验证 + 实名认证 |
| 外校学员选私有库课程 | 拒绝：「不能跨租户选课，该课程属于其他院校」 |
| 校级共享库课程尝试共享给其它学校 | 拒绝：「……是校级共享库，按需求库内课程仅限校内共享」 |
| 校际共建库课程共享给非参建学校 | 拒绝：「……是校际共建库，课程只能共享给参建单位」 |
| 机构管理员审核他机构库的证书申请 | 拒绝：「只能审核本机构主建的资源库所发起的证书申请」 |
| 其他学员目录为空 | 空态不占位、不展示 |
| 证书图片下载失败 | 自动回退为在新窗口打开原图，提示自行另存 |

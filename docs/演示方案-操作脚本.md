### 1.3 白板演示的窗口布局（关键）

教师教研白板要求**两个人同时在线**，必须双窗口并排：

| 方案 | 做法 | 说明 |
|---|---|---|
| **推荐：两套浏览器** | Chrome 窗口 A（登录 `wwq`）+ Chrome 无痕窗口 或 Firefox（登录 `wb-teacher2`） | 两套独立 localStorage，互不干扰 |

> 录制时两个窗口必须在**同一块屏幕内**（不要用双显示器），否则一段录屏只能拍到一个窗口。

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录提示「用户名或密码无效」 | 机构选错（默认国州学院） | 右上「机构」→ 选「启迪学院111」 |
| 白板第二个人登录后第一个人掉线 | 同一浏览器两个标签页共用 token | 用另一个浏览器 / 无痕窗口 |
| 白板显示「连接中…」 | SignalR 未连通 | 确认 `./dev.sh status` API 正常；刷新页面；看 Network 里 `/signalr/negotiate` 是否 200 |
| 白板两端看不到彼此 | 对方未在同一白板 / 未加入成员 | 检查两端 URL 里的白板 Id 是否一致；检查成员列表 |
| 工作室看不到「待审核」资料 | 待审那条已被审掉 | 用 `wb-teacher2` 再上传一条 |
| 课表空白 | 当周没有智能体任务 | 到「教学智能体」给课程分配一条任务并设置截止时间后发布 |
| 视频不能播放 | 资源未审核通过 | 管理员审核通过后学生/非创建者才可见 |

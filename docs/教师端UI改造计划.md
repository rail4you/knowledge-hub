# 教师端 UI 改造计划（对齐高保真原型）

> 依据原型：`易课通资源库系统-教师端-完整版（新建实训弹窗优化）(1).html`
> 目标：在不改变组件结构与业务逻辑的前提下，通过 CSS 定制层覆盖现有组件，让教师端各页面视觉对齐原型。

---

## 一、设计令牌（已落地）

在 `angular/src/styles/` 下新增三个全局 SCSS 层，从 `styles.scss` 引入：

| 文件 | 作用 |
|---|---|
| `_design-tokens.scss` | 原型配色/圆角/阴影 CSS 变量（`--kh-*`） |
| `_leptonx-overrides.scss` | 覆盖 LeptonX 主题：深蓝黑侧边栏、品牌蓝、画布底色、滚动条隐藏 |
| `_ngzorro-overrides.scss` | 覆盖 ng-zorro 基础组件：卡片/表格/标签/弹窗/分页/输入框 |

### 核心令牌
- 画布 `#f5f7fa` · 面板 `#ffffff`
- 品牌蓝 `#1890ff` · 深蓝黑侧边栏 `#0d1b30`
- 状态色：绿 `#52c41a` / 橙 `#e8871a` / 红 `#e5484d`
- 圆角：卡片 16px · 控件 10px · 胶囊 999px
- 阴影：蓝相分层阴影（卡片 / 弹窗）

### LeptonX 覆盖要点
- `--lpx-brand` 改为 `#1890ff`，去掉默认粉 `#f72585`
- 侧边栏改深蓝黑渐变，菜单项圆角 + 选中渐变高亮（含子菜单对齐修复）
- 侧边栏/导航滚动条隐藏（保留滚动能力）
- 顶部栏 / 内容区 / 底部栏改白色卡片风格

## 四、实现方式约定

1. **不改业务逻辑**：只改 HTML 结构（类名/布局）与 SCSS，Component TS 逻辑不动（除非布局需要）。
2. **CSS 定制层覆盖**：优先在 `_ngzorro-overrides.scss` 全局覆盖，页面特有样式写在组件 SCSS。
3. **复用设计令牌**：页面颜色/圆角/阴影统一用 `var(--kh-*)`。
4. **验证**：`cd angular && npx ng build --configuration development` 必须通过；lint 不新增错误。
5. **避免回归**：改完一个页面跑一次 build；涉及路由/权限/弹窗时对照 AGENTS.md 检查清单。

### 资源管理（/resources）
- Tab 改「容器式胶囊」：外层浅灰圆角条 + 内嵌白色选中胶囊，去掉多余白卡。
- 表格列宽：名称 `auto`（吃掉剩余空间 + ellipsis），版本 64px 紧凑小字，其余固定。
- 行内操作：查看 / 编辑 / 删除图标按钮，hover 高亮。
- 空态 / 加载态 / 异常态沿用原型文案与图标。

### 文档搜索（/search）
- 拆出 `search.component.html` + `search.component.scss`（原为内联样式）。
- hero 大搜索栏（左侧圆角输入 + 右侧胶囊按钮），筛选区带图标 label。
- 结果卡片：圆角、hover 上浮、类型徽标、相关度分数标签。

### 智能问答（/ai/chat）
- 左侧 `qa-sidebar`：聊天记录 / 资源文档两个可折叠分区，标题 + 数量徽标 + 箭头。
- 聊天记录按「文档问答 / 通用对话」分组，条目带图标/时间/条数/删除。
- 资源文档带搜索框 + 分类树，文档项带「已索引/未索引」标签。
- 分区内容超长时内部滚动（`overflow-y:auto`）。
- 右侧对话区：渐变文档图标 + 标题副标题 + 「AI 问答中」徽标；消息气泡 + markdown；输入条 textarea + Enter 提示 + 圆形发送按钮。

- 底部「重置 / 生成教案」按钮；生成中加载卡；结果预览卡片（标题 + 描述 + 分节列表）。

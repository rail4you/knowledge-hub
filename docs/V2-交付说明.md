## 1. 本期做了什么（按主题）

### 1.1 教学资源库主线（P1~P4）
- **审核内核**：统一审核单 `ReviewTicket` + 只追加的 `ReviewAction`；回避本人、跨级不同人、轮次冲突、并发 409、幂等哈希
- **库生命周期审核**：建库（校内库单级 / 共建库两级）、改库（变更快照，审核期按旧配置服务）、删库（**一律归档，不硬删**）
- **内容准入**：资源/课程/实训入库都要审；草稿内容与准入**合并为一条流程**；库内只展示已发布
- **共建任务**：库模板 / 任务模板 / 任务分派 / 交付验收（**验收 ≠ 发布**）
- **跨校引用**：`CourseSharedRef` 固定版本、撤销即时生效、使用事件与统计；**文件 URL 也走统一鉴权**

### 1.2 企业侧与产教（P5）
- 企业主体 `EnterpriseProfile` + 成员绑定；认证走两级审核；企业贡献入库标记 `SubmitterType=Enterprise`
- 产教合作：需求（企业发）→ 两级审核 → 需求大厅 → 学校响应 → 企业接受 → 项目台账 + 里程碑
- 就业改造：岗位企业维度、**投递简历快照**、面试时区、去向核实、统计按学生去重
- **单位有效期**（学校 + 企业）：到期禁写、读放行，全局过滤器 + 每日巡检

### 1.3 权限与资源治理（P6）
- `IResourceAccessChecker` 统一判定，覆盖 **AI 语料 / 检索结果 / 文件预览下载** 三条通道
- 检索默认只返回已审核内容；匿名在索引层即裁剪为「未挂库或公开库」
- 企业用户菜单从 60+ 项收敛到 6 组；策略悬空检查 0 项；图标注册 134/134

## 4. 关键设计决策（便于后续维护者理解"为什么这样做"）

| 决策 | 原因 |
|------|------|
| 审核状态**只追加枚举值** | 学生端 `status=3` 过滤、Meili 索引口径、历史数据都不被打断 |
| 删库**归档**而非硬删 | 审核历史/贡献记录/学习记录可追溯；文件与内容解绑但不删 |
| 任务验收 ≠ 资源发布 | 交了东西 ≠ 东西可以对外；两条独立流水线 |
| 文件访问统一走 checker | 只堵 AI/检索会被"知道 GUID 直接下载"绕过（已实测修复） |
| 单位有效期放 HTTP 过滤器 | 逐个 AppService 加校验必漏；后台任务另需显式复核 |
| 企业用户不注入全量权限 | `GrantAllPoliciesMiddleware` 曾把企业当管理角色 → 菜单泄露全平台 |

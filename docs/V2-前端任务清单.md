## FE-A 资源库审核中心（P1 已就绪，可直接开发）

### A1 ✅ `/admin/libraries` 状态列与提交/撤回
- 权限：`KnowledgeHub.ResourceLibraries`（读取）、`.Edit`（提交）
- 接口：`GET /api/app/resource-library`、`PUT /api/app/resource-library/{id}`、`DELETE .../{id}`
- 页面要点：
  - 列表新增「审核状态」列：草稿 / 待院校审核 / 待联盟终审 / 已驳回 / 变更审核中 / 删除审核中 / 已发布 / 已归档（**文字 + 颜色**，不只靠颜色）
  - 行操作：草稿 → 「提交建库审核」；`Rejected` → 「重新提交」；`Active` → 「申请删除」；`ChangePending`/`DeletePending` → 「撤回申请」
  - 变更中/待删除的库加提示条：「当前按旧配置对外服务，审核通过后生效」
- 空状态：引导「新建资源库」并提供模板入口（模板在 FE-C 上线后启用）

### A2 ✅ `/admin/libraries/audits` 审核中心（校审 / 联盟审两个 Tab）
- 权限：Tab 由 `KnowledgeHub.ResourceLibraries.Audit` / `.LeagueAudit` 控制显隐
- 接口：`GET /api/app/review-ticket?stage=&status=&targetType=&onlyMine=&filter=`、`GET /api/app/review-ticket/{id}`、`POST /api/app/review-ticket/decide`、`POST /api/app/review-ticket/{id}/withdraw`、`POST /api/app/review-ticket/{id}/resubmit`、`GET /api/app/review-ticket/my-pending-count`
- 列表列：目标类型（资源库/库内内容/任务交付/企业认证/岗位）、目标名称、动作（新建/修改/删除/准入）、提交人、提交时间、轮次、阶段、状态
- 详情抽屉：
  - 顶部：目标名称 + 当前状态 + 轮次 + 阶段进度（院校初审 → 联盟终审 两步条）
  - 中部：**变更 diff**（解析 `payloadJson`，左侧旧值右侧新值；建库显示首次配置）
  - 下部：审核时间线（`actions[]`：阶段 / 操作 / 操作人 / 时间 / 意见 / 快照）
  - 底部：通过 / 驳回（原因必填）/ 退回；`canDecide=false` 时禁用并说明原因
- 工作台红点：`my-pending-count` 轮询（与现有工作台徽标风格一致）

### A3 状态文案与本地化
- 键：`Library:Status:Draft|PendingReview|PendingLeagueReview|Rejected|ChangePending|DeletePending|Active|Archived`
- 键：`Review:Stage:School|League`、`Review:Status:Pending|Approved|Rejected|Cancelled`、`Review:Operation:Submit|Approve|Reject|Return|Withdraw`
- 注意：`KnowledgeHub:Review:*` 异常码已后端本地化，前端直接展示 `error.message` 即可

|---|------|------|------|

| T7 | 删库 → 归档 | `DELETE` → `decide{decision:0}` | 删除申请期 `status=7` 且库可用；通过后 `status=2`（Archived），`IsDeleted=false`，成员记录保留（1 条） |

| T9 | 审核单详情/列表 | `GET /review-ticket?TargetId=...` | `targetName` 正确回填、`totalStages=1`（校内库）、`canDecide=true`、时间线含"提交审核/院校初审" |

**踩坑与修复**

1. `FindLibraryAsync` 用 `using (Disable<IMultiTenant>()) { return repo.FindAsync(id); }` → 过滤器在 `await` 前释放，跨校查不到库（`targetName=None`、终审不落地）。改为 `async` + `await` 后正常。
2. `LibraryReviewHandler` 未被 DI 收录 → 改名 `LibraryReviewTargetHandler`（ABP 约定：接口 `IX` 需与类名 `*X` 对应）。
3. `ReviewAction.ActionType` → `Operation` 改名后未同步迁移 → 补 `RenameReviewActionOperation`。
4. API 是 `dotnet run`（非 watch），改代码后必须重启，否则看到的是旧行为（本轮的"审核未生效"最初就是这个原因）。

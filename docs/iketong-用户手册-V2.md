| 项 | 值 |

## 3. V2 主线总览

```
        ┌──────────────── 院校侧（qidi / guozhou）────────────────┐
 建库 ──▶ 待院校审核 ──▶ 院校初审(管理员) ──▶ 已发布
            │ 变更 / 删除同样走审核（变更审核中 / 删除审核中 / 已归档）
            └▶ 分配教师  ──▶ 教师共享资源入库 ──▶ 库内内容准入审核 ──▶ 库内发布
                                  │
              共建任务（模板 → 发布 → 协作校提交交付 → 主责校验收）
                                  │  验收 ≠ 发布（资源仍需准入审核）
                                  ▼
              跨校引用（固定「哪个库的哪个内容」→ 学生可学 → 撤销即时失效）
                                  │
        ┌──────────────── 企业侧 ────────────────┐
  学校开通企业账号 ──▶ 企业填写资料 ──▶ 企业认证（学校初审 + 联盟终审）──▶ 贡献内容
                                  └▶ 发布合作需求 ──▶ 学校响应 ──▶ 企业接受 ──▶ 项目台账
```

## 4. 角色操作指南

### 4.1 院校管理员（qidi-admin / guozhou）

#### (1) 新建教学资源库

1. 左侧「资源库管理 → 教学资源库管理」→ 右上「**新建资源库**」。
2. 填写：资源库名称、主建专业（可选，用于展示筛选）、简介、封面图（16:9，≤5MB）、建设负责人、资源库形态、排序值、是否在门户公开展示。
3. 资源库形态：
   * **校级私有库**：仅本专业/被分配教师可见可写，不对外开放自学；
   * **对外开放自学**：其他学员实名认证后可学习。
4. 确定后资源库进入「**待院校审核**」，页面提示「审核中仍按旧配置对外服务」。

#### (2) 审核资源库

1. 左侧「审核中心」，Tab「**待我审核**」→ 点「查看」。
2. 详情包含：阶段步进（如「1 院校初审 · 共 1 级审核」）、提交的变更内容表、审核历程。
3. 「**通过**」/「**驳回**」（驳回必须填原因，提交人据此修改）。
4. **不能自审**：自己提交的单一律没有通过/驳回按钮，只显示「当前阶段不由你审核，或你正是提交人（不能自审）」。

> 审核层级：校内库 = 1 级（院校初审）；**院校共建库 = 2 级**（院校初审 → 联盟终审，终审须由 `league-admin` 执行，与初审人不能同一人）。

#### (3) 驳回后重新提交

被驳回后，提交人在「审核中心 → 我提交的」→ 查看 → 点「**重新提交**」，同一单据轮次 +1（不会与历史割裂）。

#### (4) 分配教师 / 共建学校

资源库列表「操作」列：

| 操作 | 作用 |
|---|---|
| 共建学校 | 把其他学校设为协作校（共建库可见性依赖它） |
| 分配教师 | 指定教师进入该库（**私有库必须分配，否则教师看不到**） |
| 编辑 | 改名/简介等，走「变更审核」，审核通过前旧配置继续服务 |
| 归档 | 立即下线（不删除） |
| 申请删除 | 提交删除审核 → 通过后转「已归档」，**行保留不物理删除** |

#### (5) 开通企业账号

1. 左侧「产教合作 → **企业账号**」Tab → 「**开通企业账号**」。
2. 填用户名 / 姓名 / 初始密码（≥6 位）/ 公司名（新建企业档案，初始为「草稿」）。
3. 企业账号登录后直达「企业工作台」，自行补资料并提交认证。

#### (6) 学校有效期（平台侧）

「平台运维 → 学校有效期」：设置各校有效期止与「到期后只读」。到期后该校**读放行、写拒绝**（新建/编辑/删除/发布/审核/授权均被拒，提示「单位已过有效期」），续期后立即恢复。

### 4.2 教师（wwq / guozhou-teacher）

#### (1) 共享资源入库

1. 「资源库管理 → 教学资源库工作台」→ 目标库卡片 →「**共享资源**」。
2. 弹窗有「库内容 / 共享资源」两个页签：
   * 「库内容」= 已关联到本库的内容（含状态：已发布 / 审核中）；
   * 「共享资源」= 可添加的候选（**只列本校资源**，且不重复列出已关联内容）。
3. 勾选内容 → 「共享选中（1）」→ 提示「已提交 N 项入库审核」。
4. **入库不等于发布**：资源进入「审核中」，需院校初审（共建库再加联盟终审）通过后才在库内可见。

#### (2) 提交共建任务交付物

1. 「资源库管理 → **我的共建任务**」→ 找到主责校/协作校发布的任务。
2. 每个交付项右侧点「**提交**」→ 选交付项 + 选资源（只列自己创建、且未入库的资源）→ 备注 → 「提交（同步发起准入审核）」。

#### (3) 跨校引用

1. 「资源库管理 → **我的跨校引用**」→ 「**引用资源到课程**」。
2. 三步选择：来源资源库 → 资源（**只列已发布到库的内容**）→ 目标课程（本校，需是课程负责人或院校管理员）。
3. 成功后列表出现「生效中」，统计卡「生效引用 +1」。
4. 撤销：点「撤销」→ 确认 → 立即变「已撤销」，学生端随即失去访问权。

### 4.3 平台 / 联盟管理员（admin / league-admin）

* **院校初审**：`admin` 在「审核中心」处理各校待审单（共建库通过后自动进入「待联盟终审」）。
* **联盟终审**：`league-admin` 在「审核中心」处理待联盟终审的单；**同一单据两级不能同一人**。
* **审核中心三个 Tab**：「待我审核」/「我提交的」/「已处理」，可按目标 Id 搜索。
* **企业认证终审**、**合作需求终审**同样走两级（学校初审 → 联盟终审）。
* **平台运维**：学校有效期、检索统计、资源进度等。

### 4.4 企业用户（qidi-ent）

1. 登录后**直达** `/enterprise/workbench`，侧边栏只保留 6 组（系统工作台 / 资源库管理 / 企业工作台 / 资源中心 / AI 中心 / 就业管理）。
2. **编辑资料**：企业工作台资料卡「编辑资料」→ 填统一社会信用代码 / 行业 / 联系人 / 邮箱 / 简介 → 保存。
   > 统一社会信用代码是**必填项**：没填完点「提交企业认证」会提示「请先完善企业资料」。
3. **提交企业认证** → 状态「待审核」→ 学校初审 + 联盟终审 → 「已认证」。
   > 未认证时**不能**向资源库贡献内容（提示「企业尚未通过认证或已过有效期…」），可以建需求草稿。
4. **贡献内容**：认证后可在「教学资源库工作台」看到本校库 →「共享资源」提交，走**准入审核**（企业贡献不免审，发布记录标记为企业提交）。
5. **合作需求**：「企业工作台 → 合作需求 → 新建需求」→ 选合作类型 / 可见范围（仅入驻校 / 联盟内 / 平台公开）/ 专业方向 / 地区 / 背景与目标 / 企业投入 / 条件要求 / 周期规模 / 交付验收 / 知识产权 →「保存并提交审核」。
6. **处理学校响应**：「合作需求」行「查看响应」→ 接受 / 拒绝；已接受的响应可「**建项目**」→ 进入「项目台账」。

### 4.5 学生（zmq）

* 学生空间菜单只有学习类（课程中心 / 我的学习 / 智学分析 / 资源库 / 微专业 / 课堂任务 / 实训项目 / AI 助手 / 智能搜索 / 就业 / 资讯），**看不到任何管理端菜单**（资源库管理、审核中心、共建任务、企业工作台）。
* 「课程中心 → 课程详情 → 课程资源」页签底部有「**跨校共享资源**」：
  * 可学习 → 点击进入资源详情；
  * 不可学习（未选课 / 引用被撤销 / 来源已下架）→ 显示「**资源暂不可用**」并给出原因。
* 跨校引用的受众是「目标课程里有学习关系的学生」，教师能预览 ≠ 全班自动获得学习权。

## 5. 状态与术语对照

| 对象 | 状态 | 含义 |
|---|---|---|
| 教学资源库 | 草稿 / 待院校审核 / 已发布 / 变更审核中 / 删除审核中 / 已归档 | 审核中一律「按旧配置对外服务」 |
| 库内内容准入 | 审核中 / 已发布 / 已驳回 / 已下架 | 只有「已发布」对所有人可见；「审核中」仅提交人与院校管理员可见 |
| 审核单 | 待审核 / 已通过 / 已驳回 / 已取消 | 驳回后由提交人「重新提交」，轮次 +1 |
| 审核阶段 | 院校初审 → 联盟终审 | 1 级（校内库）/ 2 级（共建库、企业认证、合作需求） |
| 共建任务 | 草稿 / 已发布 / 进行中 / 待验收 / 已验收 / 已退回 / 已关闭 | **验收 ≠ 发布** |
| 产教需求 | 草稿 / 待审核 / 已发布 / 已驳回 / 已关闭 | 审核通过才进需求大厅 |
| 合作项目 | 洽谈确认 / 执行中 / 待验收 / 已归档 / 已终止 | 归档前必须填写验收意见 |

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 教师在「教学资源库工作台」看不到库 | 私有库需管理员「分配教师」；共建国教师需主建校显式分配 | 请院校管理员分配后再登录 |
| 共享资源时提示「资源不存在。」 | 候选列表只列**本校**资源，他校资源无法入本校库 | 改选本校资源 |
| 共享后库内看不到该内容 | 入库进入「审核中」，需院校初审（共建库再加联盟终审） | 在审核中心处理 |
| 我提交的内容在「库内容」里看不到 | 「审核中」按**准入提交人**可见；若仍看不到请刷新 | 刷新页面；必要时联系院校管理员 |
| 点「通过」没反应 | 不能自审（自己提交的单） | 换一位院校管理员 / 联盟管理员处理 |
| 共建库初审后还要再审 | 共建库两级审核：院校初审 → 联盟终审 | 用 `league-admin` 终审 |
| 驳回后找不到「重新提交」 | 只有**提交人本人**且单据处于「已驳回」才显示 | 确认是本人提交的账号 |
| 企业点「提交企业认证」提示「请先完善企业资料」 | 统一社会信用代码等资料未填 | 先「编辑资料」补全 |
| 企业看不到任何资源库 | 企业账号不占教师编制，但认证后可见本校库 | 先完成企业认证 |
| 企业无法贡献内容 | 未认证 / 已过有效期 | 完成认证或联系平台续期 |
| 学校过期后什么都做不了 | 到期后写操作被拒（读放行） | 平台在「学校有效期」续期 |
| 归档项目被拒 | 归档前必须填写验收意见 | 在项目详情「归档」时填写验收意见 |
| 学生说看不到共享资源 | 未选该课程 / 引用已撤销 / 来源已下架 | 页面会显示「资源暂不可用」及原因 |

## 7. 运维附录（平台管理员）

### 7.1 部署到 iketong

```bash
cd etc/docker
./deploy-iketong.sh all        # 完整部署（构建 + 推送 + 远端编排 + 宝塔站点 + SSL）
./deploy-iketong.sh api        # 仅后端
./deploy-iketong.sh angular    # 仅前端
./deploy-iketong.sh migrator   # 仅迁移工具并执行数据库迁移
./deploy-iketong.sh sync       # 同步配置（.env / compose / nginx / dynamic-env）
./deploy-iketong.sh status     # 服务状态
```

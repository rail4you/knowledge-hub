## 2. 实现约束（已锁定决策的落地口径）

| 约束 | 落地含义（开发时必须遵守） |
|------|--------------------------|
| 校内库单级审核 | `ReviewPolicyResolver` 对 `Library.Visibility ∈ {Private, Public}` 只返回 `[School]` 阶段；共建库返回 `[School, League]` |
| 内容审核与准入合并 | 草稿内容入库只生成**一条** ticket（两阶段）；已发布内容只生成**单级准入** ticket；不得出现"同一次入库等两次审核" |
| 两角色不变 | 只新增 `ResourceLibraries.Audit`（SchoolAdmin）与 `.LeagueAudit`（LeagueAdmin）；**不新增系统角色**；库内职责走 `LibraryRoleAssignment` |
| 状态映射不重建 | `ResourceStatus` 只加映射，不改 0~5；学生端 `status=3` 过滤、Meili 索引口径不动 |
| 删库＝归档 | `DeleteAsync` 只把库推进 `DeletePending → Archived`；**任何情况下不 DELETE 库行**；成员/教师/审核历史保留 |
| 跨校引用本期交付 | `CourseSharedRef` + 学生放行分支 + 撤销/升级 + 使用事件 |
| 单位有效期（学校+企业） | 写操作硬门禁、读放行；`OrganizationValidityFilter` 全局生效；异步任务执行时复核；续期只恢复不扩权 |
| 企业用户在校内租户 | 学校管理员可创建/管理本企 `EnterpriseUser`；业务归属由 `EnterpriseProfile` 决定，不用 `TenantId` 当企业身份 |
| 就业全量 | 投递快照冻结、企业维度隔离、面试四要素、多去向 + 主去向 + 审核、统计去重口径 |
| 受控文件流 | 不引入 CDN 签名 URL；撤销靠实时鉴权即时生效 |

**开工前环境前提**
1. `dotnet build` 可用（我执行编译验证）；数据库迁移与 `./dev.sh migrate` 由你执行（我不启动服务）。
2. 代理重生成（`abp generate-proxy -t ng`）需要 API 运行中 → 涉及 V2-112 / 208 / 306 / 406 / 516 等前端任务时，需要你先把 `./dev.sh start api` 起来，或授权我在该步运行。
3. 每个迁移我会给出名称与 SQL 影响范围，执行由你确认。

# 学生端页面改造规范（v5）

> 适用范围：`angular/src/app/student/**` 全部页面
> 参考原型：`new_design/易课通_全专业前端交互原型.html` + `new_design/source/work/*.js`
> 标杆实现：`angular/src/app/student/dashboard/`（学生工作台）

---

## 一、改造目标

以新原型为**结构与交互规格**，把学生端页面重做到「信息架构 + 视觉语言对齐原型」，
同时**所有数据接真实 API**，不做假数据、不做假入口。

原型是评审件：全部数据是内存字面量、角色门禁在前端字符串比较。**只可参考它的页面结构、
区块顺序、状态机和视觉语言**，不可照抄它的数据与鉴权做法。

---

## 二、设计令牌（唯一来源）

色值只在 `angular/src/styles/_palette.scss`；CSS 变量在 `angular/src/styles/_design-tokens.scss`。

**新代码一律用 CSS 变量**：

```scss
var(--kh-accent)      // 主色 #087f7a
var(--kh-ink)         // 正文 #203b40
var(--kh-muted)       // 次要文字 #607379
var(--kh-line)        // 描边 #e0e8e5
var(--kh-canvas)      // 页面底 #f5f7f6
var(--kh-accent-soft) // 浅底 #eaf3ef
var(--kh-gold)        // 沙金 #d1ad73
var(--kh-ok) / var(--kh-warn) / var(--kh-bad) / var(--kh-info)
var(--kh-r-control)   // 8px
var(--kh-r-card)      // 14px
var(--kh-shadow-card)
```

**存量 SCSS 变量**（`app/student/styles/_student-design.scss`，`@use ... as ds`）已改为引用同一份调色板，
存量文件不用改也能拿到新色值：

```scss
ds.$student-primary / ds.$student-text / ds.$student-bg / ds.$student-border / ds.$student-radius ...
```

> 半径已由 3px 调整为 8px（控件）、14px（卡片），与原型一致。

**禁止**：在组件 SCSS 里硬编码色值（`#087f7a` 等）与新的断点像素值。

## 三、共享组件（必须复用，不要各写各的）

位置：`angular/src/app/student/shared/`

| 组件 | 选择器 | 用法 |
|---|---|---|
| 骨架屏 | `<app-student-skeleton>` | `[variant]="'text'\|'cards'\|'list'\|'stats'\|'detail'"` `[rows]` `[cards]` |
| 空状态 | `<app-student-empty>` | `[variant]="'data'\|'result'\|'permission'\|'offline'"` `[title]` `[description]` `[actionLabel]` `(action)` |
| 错误态 | `<app-student-error>` | `[title]` `[detail]` `[retryable]` `(retry)` |
| 分页条 | `<app-student-pagination>` | `[total]` `[pageIndex]` `[pageSize]` `[showSizeChanger]` `(pageChange)` |
| 页头 | `<app-student-hero>` | `[title]` `[description]` `[stats]`（存量组件，当前学生端页面各自实现了页头，尚未统一接入） |

### 四态规范（每个列表/详情页都要有）

```
loading → <app-student-skeleton>
error   → <app-student-error (retry)="reload()">
empty   → <app-student-empty>   ← 按语义选 variant
data    → 正常渲染
```

`empty` 与 `error` **不能混用**：
- 「本来就没有数据」→ `variant="data"`
- 「筛选条件太窄」→ `variant="result"`（要给出重置筛选入口）
- 「没有权限」→ `variant="permission"`（不给重试）
- 「服务挂了」→ `<app-student-error>`（给重试）

## 四、数据规范

1. **只用真实 API**。数据来自 `angular/src/app/proxy/**`（生成的）或已有的手写 service。
2. **不做假数据**。找不到数据就：
   - 有对应接口 → 接上；
   - 没有对应接口 → 用 `app-student-empty` 如实说明「XX 建设后开放」，或在本页用真实数据替代，并在交付说明里列出。
3. **服务端分页**。禁止 `maxResultCount: 200` 再前端 slice 的写法。用后端 `PagedResultDto` + `<app-student-pagination>`。
   - 传 `skipCount` / `maxResultCount` / `sorting`。
   - 页码变化时重查。
4. **筛选写进 URL**。用 `ActivatedRoute.queryParams` 读取、`router.navigate` 写回，刷新不丢。
5. **不要用 `console.log` 调试**；不要在组件里塞硬编码的中文业务数据（枚举映射表除外，如难度/题型标签）。
6. **`.toPromise()` 禁用**（RxJS 8 已移除），统一 `subscribe` 或 `firstValueFrom`。
7. **枚举标签**：优先用后端返回的枚举值 + 本地映射表；映射表集中放在该模块的一个 `*-labels.ts` 里，不要散落。

## 五、页面骨架（推荐）

```html
<div class="page">
  <app-student-hero [title]="..." [description]="..." [stats]="stats()" />

  <section class="panel">
    <div class="panel__head">
      <h2>...</h2>
      <div class="panel__tools"><!-- 筛选 --></div>
    </div>

    @if (loading()) {
      <app-student-skeleton variant="list" [rows]="4" />
    } @else if (loadFailed()) {
      <app-student-error (retry)="reload()" />
    } @else if (!items().length) {
      <app-student-empty variant="data" ... />
    } @else {
      <!-- 内容 -->
      <app-student-pagination
        [total]="total()"
        [pageIndex]="pageIndex()"
        [pageSize]="pageSize()"
        (pageChange)="onPage($event)" />
    }
  </section>
</div>
```

样式约定：
- 页面容器复用 `ds.$student-container` mixin（`@include ds.student-container;`）。
- 卡片：`background: var(--kh-panel); border: 1px solid var(--kh-border); border-radius: ds.$student-radius-lg;`
- 区块标题：`@include ds.section-heading;`
- 焦点可见：`@include ds.focus-ring;`

## 六、Angular 约定

- standalone 组件；`ChangeDetectionStrategy.OnPush`
- 状态用 `signal()` / `computed()`；输入用 `input()`，输出用 `output()`
- 依赖用 `inject()`，不用构造函数注入
- 模板用原生控制流 `@if` / `@for` / `@switch`，`@for` 必须写 `track`
- 不新增第三方依赖

## 七、原型怎么读

原型文件：`new_design/source/work/`
- `pages.json` —— 101 个视图的注册表（id / title / group / subtitle）
- `prototype.js` / `shared.js` / `redesign.js` / `integrated.js` / `workbenches.js` —— 各页面的 mock 结构与交互
- `reconciliation.js` / `library-reference.js` / `ownership.js` / `journey.js` —— 共建共享 / 课程库 / 数据归属 / 角色流转
- `prototype.css` / `redesign.css` / `workbenches.css` / `integrated.css` —— 视觉语言

> ⚠️ 装配顺序：`prototype → shared → redesign → library-reference → integrated → reconciliation → workbenches`，
> **后者覆盖前者**。同一个 `views.xxx` 被多次赋值时，最终生效的是最后那份。
> 读源文件判断真实行为时必须按此顺序。

原型的四个缺口（本项目自行修正，不要照抄）：
1. 无 loading / skeleton / 错误页 / 403 / 字段级校验 → 本项目已补共享组件
2. 筛选用模块级变量，刷新即丢 → 本项目一律写 URL
3. `versions` / `shared-members` / `shared-stats` 学生可打开 → 不实现为学生路由
4. `career` 与 `resume-center` 两套简历并存 → 本轮沿用现网 `StudentResume` 设计，不改后端
